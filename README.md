# 한국경제 AI 교육 포트폴리오

`dist/article.html`을 브라우저로 열면 시작합니다. 서버 없이도 메뉴 이동, 기사 본문 열기, 이미지 확대가 작동합니다.

- `dist/article.html`: 매거진형 기사 목록
- `dist/image.html`: 비대칭 이미지 갤러리
- `dist/video.html`: 영상 기획 및 제작 노트
- `dist/final.html`: 최종 프로젝트 소개
- `dist/style.css`: 공통 디자인 및 모바일 반응형 스타일
- `dist/script.js`: 기사 상세 및 이미지 확대
- `dist/index.html`: 기사 페이지와 동일한 시작 화면

현재 글과 프로젝트 내용은 교육용 임시 콘텐츠이며 사진은 Unsplash 참고 사진입니다. 온라인 상태에서 사진과 웹폰트를 불러옵니다. 실제 영상 파일은 포함되어 있지 않습니다.

각 HTML에서 제목, 설명, 이미지 주소를 교체할 수 있습니다. 기사 상세 본문은 `dist/script.js`의 articles 배열에서 수정합니다. `make-portfolio.cjs`는 최초 파일 생성용이므로 HTML을 직접 수정한 뒤 재실행하면 수정 내용이 덮어써집니다.

현재 버전은 정적 포트폴리오입니다. 파일 업로드 및 서버 저장 기능은 포함하지 않습니다. 자료는 HTML 또는 이미지·영상 파일을 수정하여 게시합니다.
